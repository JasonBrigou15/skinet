# Skinet – E-commerce applicatie (Angular & .NET Core)

## Over dit project
Dit project is gebaseerd op een **online course (.NET 9 & Angular 20)** waarin een volledige proof-of-concept e-commerce store wordt gebouwd.  
Het doel van dit project was om **een complete applicatie van nul tot eindproduct** te ontwikkelen en daarbij de belangrijkste concepten van Angular en .NET Core in praktijk te brengen.

## Technologieën
- **Frontend**: Angular  
- **Backend**: ASP.NET Core Web API  
- **Database**: SQL Server & Redis  
- **CI/CD**: GitHub Actions  
- **Cloud**: Deployment naar Azure  
- **Styling**: Angular Material & Tailwind CSS  
- **Payments**: Stripe
- **Realtime**: SignalR  

## Functionaliteiten
- Productoverzicht met **paging, filtering, sorting en searching**  
- **Winkelmandje** met Redis caching  
- **Gebruikersregistratie & login** via ASP.NET Identity  
- **Role-based authentication** (gebruiker/admin)  
- **Ordersysteem** (van winkelmandje naar bestelling)  
- **Lazy loaded routes** in Angular  
- **Meerstaps formulier** met Angular Reactive Forms  
- **Betalingen** via Stripe  
- **Realtime updates** met SignalR  

## Wat ik geleerd heb
- Werken met Angular modules, routing en reactive forms  
- Repository, Unit of Work & Specification pattern in .NET Core  
- Gebruik van meerdere DbContexts als context boundaries  
- Opzetten van CI/CD pipelines met GitHub Actions  
- Basis cloud deployment naar Azure  
- Bouwen van een moderne UI met Angular Material en Tailwind
